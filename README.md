🎓 Student Performance Analytics Engine

📌 Project Overview

Student Performance Analytics Engine is a Python-based project designed to analyze student academic performance using NumPy, Pandas and Matplotlib.

It calculates student averages, percentages, grades and identifies class toppers through data analysis and visualization.

🚀 Features

* Student Marks Management
* Average Marks Calculation
* Percentage Calculation
* Grade Calculation
* Pass/Fail Analysis
* Topper Identification
* Subject-wise Performance Analysis
* Data Visualization using Matplotlib
* Student Ranking
* CSV Report Generation
* Statistical Analysis

🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Google Colab

▶️ How to Run

1. Download the project notebook.
2. Open Google Colab.
3. Upload the .ipynb file.
4. Run all cells sequentially.
5. View the student performance analysis and graphs.

📊 Output

* Student performance dashboard
* Student grades and percentages
* Class topper information
* Subject-wise analysis
* Performance graphs
* CSV report

🎯 Objective

The main objective of this project is to understand NumPy operations and apply Python programming to real-world student performance analysis.
